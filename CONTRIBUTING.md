# Contributing

Thanks for your interest in contributing. Each repository may have additional instructions; check its README and project documentation before making changes.

## Before opening an issue

- Search existing issues and discussions to avoid duplicates.
- Include enough detail to reproduce a bug, such as the relevant environment, steps, and expected and actual results.
- For questions or ideas, use the repository's discussions if they are enabled.

## Changes

- Keep changes focused and follow the conventions already used by the project.
- Add or update tests and documentation when appropriate.
- Run the relevant checks locally and report which checks you ran.
- Do not include credentials, access tokens, private data, or unrelated generated files.

## Pull requests

- Explain the problem and the reason for the change.
- Link any related issue.
- Summarize the important changes and the checks performed.
- Keep the pull request focused; separate unrelated changes into separate pull requests.

## Use of AI tools

AI tools may assist with research, writing, coding, testing, or translation. You remain responsible for everything you submit.

- Review and understand all AI-assisted changes before submitting them. You must be able to explain their purpose and behavior.
- Do not submit unreviewed AI output or allow an autonomous agent to independently open issues or pull requests, or post comments or review responses.
- Keep issue and review discussions in your own words. AI may help improve clarity or grammar, but it must not replace your understanding or answers to maintainers.
- Briefly disclose AI assistance in your pull request description when it materially contributed to the changes.
- Do not provide AI tools with secrets, credentials, private data, or material you are not authorized to share.

Repository-specific guidance takes precedence over these defaults.
