# Security Policy

Security support and supported versions may differ between repositories. Check the repository's README, release notes, or documentation for project-specific details.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

When available, use GitHub's private vulnerability reporting feature in the repository's **Security** tab. If private reporting is not enabled, contact the repository maintainers through a private channel listed in that repository's documentation or organization profile. Avoid sharing sensitive details until you have a private channel.

Please include the affected repository and version, the potential impact, and steps to reproduce the issue. You may redact or withhold details that could expose users before a fix is available.

We will acknowledge reports as soon as practical and coordinate next steps and disclosure with the reporter. Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing a vulnerability.

Repository-specific security instructions take precedence over these defaults.
